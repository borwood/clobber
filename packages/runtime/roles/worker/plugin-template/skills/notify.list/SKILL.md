# notify.list

```
clobber notify list
```

Lists all pending and delivered notifications addressed to your agent. Read
these to catch messages from the system, the manager, or CI feedback that
arrived while you were working.

```
clobber notify list
```

Run `clobber notify ack <id>` to acknowledge each notification once you have
acted on it. See `clobber notify --help` for full details.
